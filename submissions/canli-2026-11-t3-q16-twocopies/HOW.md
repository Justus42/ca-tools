Construction: a covering perfect hash family of strength 3 with three rows, CPHF(3; 546, 16, 3), from two copies of the points of PG(2, 16). Points are the elements x of GF(16^3)^* / GF(16)^*, with GF(16^3) = GF(16)[b]/(b^3 - c) for a non-cube c of GF(16) (here c = x, the class of the Conway generator). The columns are B_x = (x, x^-1, x) and E_x = (x, b x^-1, b x), one of each for every point x: 2 x 273 = 546 columns. Rows 1-2 of the B columns are the pair of Raaphorst, Moura and Stevens (2014). Any three columns have a row whose three vectors are linearly independent: for q = 4^s the point b is the nucleus of the conic formed by the inverses of the line through 1 and b, which settles the triples that mix B and E columns (Colbourn, Ingalls, Jedwab, Saaltink, Smith and Stevens (2024) use the same cubic and nucleus for orthogoval planes on one point set). By the theorem of Sherwood, Martirosyan and Colbourn (2006) the family gives CA(3(16^3 - 1) + 1; 3, 546, 16) = CA(12286; 3, 546, 16). The construction works for every q = 4^s and gives CA(3q^3 - 2; 3, 2(q^2+q+1), q); the proof is sketched in the README linked below, and a note with the full proof is in preparation.

Built from: nothing. There is no search and no starting array: the family is computed from the field.

Program: https://github.com/arhancanli/quantavane-covering-arrays/tree/984c4cb/three-row (MIT). Build `cc -O2 -o kd code/kummer_dump.c`, run `./kd 4 0 dump.txt` (q = 2^4; GF(16) = GF(2)[x]/(x^4 + x + 1) in the Conway coding, c = x, points in the order (1, a1, a2), (0, 1, a2), (0, 0, 1) of their coordinates in the basis 1, b, b^2), then `python3 code/to_rows.py dump.txt out.txt`, which writes each vector in base 16, most significant digit first. out.txt is byte for byte the file here. Checks: code/kummer3.c (GF(16)[b]/(b^3 - c), determinants) and code/singer_check.c (Singer exponents and a planar difference set, written separately) both find every triple covered at q = 4, 16, 64 and 256 and refuse their red controls (three-row/checks/); tools/cphf/cphfcheck.c of this repository, mode full, on this file: 26,979,680 t-sets, 0 uncovered (a file with one entry changed leaves 152 uncovered).
