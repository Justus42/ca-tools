Construction: row-deletion simulated annealing with tabu repair (post-optimisation in the sense of Nayeri, Colbourn and Konjevod), run as a successive-halving sweep over many table entries at once: each array starts from the current table array for its entry and the search tries to remove one row at a time while keeping every t-way combination covered. CA(90;3,43,3) and CA(91;3,44,3) were first grown by one and two columns from Bai XunDi's CA(90;3,42,3) by annealing at fixed N.
Built from: the table's own arrays for each entry (named per row in claims.csv `construction` and `credit`), all openly licensed table files; none is a Torres-Jimenez array or derived from one.
Program: https://github.com/alexanderlvdi/covering-array-search (library/solvers/covering-arrays/). Strength 3: `python3 ca_sweep.py targets.tsv sweep <worker> <workers> 9.8 60` with `ca_focus.c` (compiled -O3 -static); strengths 2 and 4: `ca_sweep_t.py` with `ca_focus_t.c`. Each run is seeded from the clock, so a rerun finds an array of the same size but not the same array; the submitted files are the certificates.

Submitter: Alexander LaVerdi, Independent. Built with an AI research agent I developed.
