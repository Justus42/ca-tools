# smolen-2026-11-cyclo-1: 66 best known sizes by cyclotomic arrays

The arrays are not stored. Each has a construction certificate in this folder, and tools/construction_cert.py rebuilds it and checks its strength.

Construction: the cyclotomic arrays of C. J. Colbourn, Covering arrays from cyclotomy, Des. Codes Cryptogr. 55 (2010) 201-219. For a prime p with v dividing p - 1 and a primitive root g, the class of a nonzero x is its exponent to base g, mod v. The plain array has rows and columns indexed by GF(p) and entry the class of c - r (0 on the diagonal): p x p, 44 sizes here. The shifted array is the plain one with s added mod v, for each s in 0..v-1, and a last column s: vp x (p + 1), 22 sizes here. Each size takes the first k columns. 65 of the sizes are cited in the table as "Cyclotomy (Colbourn)" and one as "Cyclic, derived (Colbourn-Keri)"; every one equals the cited best known value, and none had an array in the table.

Built from: nothing. No search and no starting array; every array is computed from p, v and g. No array of Torres-Jimenez is used.

Program: tools/construction_cert.py of this repository, kind cyclo-1 (tools/CONSTRUCTION_CERT.md, "cyclo-1"). The strength of a cyclotomic array for a given prime is a computation, not a theorem, and the checker does it exactly. The maps x -> ax + b (a a power of g^v) on the columns, with the same map on the row index, carry the array onto itself, so every t-set of columns has the same coverage as a set containing column 0 and one of 1, g, ..., g^(v-1). The checker confirms the symmetry, writes the array with those columns first, and runs ca_verify (this repository) on exactly those sets as v units of its shards by column pairs, each required to be VERIFIED with the expected number of sets. The proof is in CONSTRUCTION_CERT.md; tools/tests_construction/test_cyclo.py compares the verdict with ca_verify on the whole array for 196 arrays (94 covering, 102 not) and finds no disagreement. Each certificate here was made by running that check and hashing the rebuilt array; about 26 minutes for all 66 on two cores. Rebuild one with `python3 tools/construction_cert.py submissions/smolen-2026-11-cyclo-1/CA_523_5_523_2.cert.json --write CA.txt`.

Found by the ca-tools engine's closure (the CAs construction CYCLOTOMY reaches these sizes); the certificates are this project's. 77 more cyclotomic sizes of the table need a longer check than these (an estimated 10^12 row-sets or more) and are not included here.
