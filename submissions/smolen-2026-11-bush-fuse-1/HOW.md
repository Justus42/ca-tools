# smolen-2026-11-bush-fuse-1: 35 best known sizes by Bush orthogonal arrays, fused

The arrays are not stored. Each has a construction certificate in this folder, and tools/construction_cert.py rebuilds it.

Construction: the Bush orthogonal array OA(q^t; t, k, q) of index one, q a prime power, t <= q, t <= k <= q + 1 (K. A. Bush, Orthogonal arrays of index unity, Ann. Math. Statist. 23 (1952) 426-434): one row per polynomial of degree below t over GF(q), its values at the field elements, and its leading coefficient as column q + 1. For 9 sizes this is the array itself (kind bush-1, v = q). For the other 26, r = q - v symbols are fused one at a time by Lemma 3.1 of C. J. Colbourn, G. Keri, P. P. Rivas Soriano and J.-C. Schlage-Puchta, Covering and radius-covering arrays: constructions and classification, Discrete Appl. Math. 158 (2010) 1158-1180, each fuse removing two rows (kind fuse-1 with a Bush input and "times": r), giving CA(q^t - 2r; t, k, v). Fields: GF(p) for p prime; GF(16) = GF(2)[x]/(x^4 + x + 1), GF(25) = GF(5)[x]/(x^2 + x + 2) and GF(27) = GF(3)[x]/(x^3 + 2x + 1), each checked to be a field by the certificate checker. Every size equals the best known value the table cites (Colbourn's tables, "orthogonal array" and "orthogonal array fuse"), and none had an array in the table.

Built from: nothing. No search and no starting array: every array is computed from its field. No array of Torres-Jimenez is used.

Program: tools/construction_cert.py of this repository (kinds bush-1 and fuse-1, CONSTRUCTION_CERT.md, "Fusing several symbols, and the Bush orthogonal array as input"). Each certificate was made by rebuilding its array once with that program, hashing it, and writing the hash as array_sha256; all checks of the kind passed (field, bush hypotheses, fuse rows, symbols, N, k, sha256). Rebuild one with `python3 tools/construction_cert.py submissions/smolen-2026-11-bush-fuse-1/CA_707271_4_30_24.cert.json --write CA.txt`. The theorems are checked on twelve fused and five plain Bush arrays by ca_verify in tools/tests_construction/test_bush_fuse.py. The largest certificate here is 940,917,620 cells, inside the checker's limit of 10^9; twelve more sizes of this kind are larger and are not included.

Found by the ca-tools engine's closure (the CAs construction fuseBushtCA reaches these sizes); the certificates are this project's.
