Construction: simulated annealing with row reduction and SAT repair. The search started from the cyclotomic CA(152; 3, 38, 4) with 33 added rows and a 39th column, filled by simulated annealing on the triples that meet the new column, which gave CA(185; 3, 39, 4). It then removed rows one at a time, each annealing run warm-started from the previous array with a row deleted. At N = 182 annealing stopped one triple short, and a SAT solver re-solved a few freed rows of those arrays. The last run started from a 180-row array with 3 uncovered tuples and reached 0 after 205,022,857 moves.

Built from: the cyclotomic CA(152; 3, 38, 4) of Colbourn (Covering arrays from cyclotomy, Des. Codes Cryptogr. 55 (2010) 201-219), rebuilt from that construction; nothing else.

Program: https://github.com/seankim-business/ca-180-3-39-4 (src/col38.c for the 39th column, src/casa.c for the annealing, src/mkinit.py to delete a row, src/sat_repair.py for the SAT repair). The final step ran `casa P2.txt 180 39 0 0 19000 3939002 0.45 out.txt` (seed 3939002, start temperature 0.45, 19000 s budget), where P2.txt is a 180-row array with 3 uncovered tuples from the previous run. To verify: `cc -O3 -pthread -o ca_verify ca_verify.c && ./ca_verify CA_180_3_39_4.txt 3 4`.
